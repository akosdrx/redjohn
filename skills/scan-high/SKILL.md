# High scan profile

Complete the standard profile first, then deepen evidence-supported high-impact surfaces. Build role/object/action matrices and inspect client-side trust, business logic, supply-chain integrity and API-specific authorization. For source targets, trace data flows across modules without executing target code. For web targets, validate chains using synthetic data, bounded request rates and reversible proofs. Concurrency tests require explicit engagement permission and a safe fixture.

Route through the standard skills plus 25, 32, 45, 55, 58, 65 and 85 where applicable. Infrastructure skills 80 and 82 apply only when that exact stack is part of the authorized target. Delegate separate hypotheses, reconcile duplicate findings and spend the remaining budget on highest-confidence branches. Document every excluded surface.

This profile is inherited by all descendants. Load the master methodology and relevant surface skills with builtin:load_skill. Read referenced files with builtin:read_skill_file. Finish only with evidence references, negative coverage and clear limitations.
